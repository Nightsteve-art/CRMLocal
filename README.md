# CRM NEW

Полностью переписанная современная CRM для Eko-Production. Это самостоятельное приложение, созданное на основании бизнес-процессов предыдущей CRM без копирования её монолитной архитектуры.

## Реализовано

- авторизация и роли сотрудников;
- современная рабочая панель;
- контрагенты и контактные данные;
- коммерческие предложения и статусы;
- заказы, паспорт заказа, позиции и производственные статусы;
- склад, остатки, резервы, приход/расход и журнал операций;
- заявки на материалы и снабжение;
- задачи швейного производства;
- производственный Kanban с drag-and-drop;
- адаптивный интерфейс для компьютера и телефона.

## Быстрый запуск Windows

1. Переключитесь на ветку `CRM_NEW`.
2. Запустите `start.bat`.
3. Откройте `http://localhost:5000`.
4. Первый вход: `admin` / `admin123`.
5. Сразу смените пароль администратора для рабочего использования.

## Ручной запуск

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python run.py
```

## Структура

- `crm/__init__.py` — фабрика приложения и инициализация БД;
- `crm/models.py` — новая нормализованная модель данных;
- `crm/routes.py` — бизнес-модули и API;
- `crm/templates/` — единый интерфейс;
- `crm/static/` — дизайн и интерактивность;
- `instance/crm_new.db` — новая локальная SQLite БД.

## Перенос старых данных

Схема CRM NEW намеренно отличается от старой монолитной базы. Старый файл БД нельзя просто подменить. Для переноса следует использовать отдельный контролируемый скрипт импорта после резервного копирования. Исходная CRM и её база не изменяются этой веткой.

## Production

Установите безопасные значения `SECRET_KEY`, `DATABASE_URL`, `ADMIN_PASSWORD`; отключите debug в `run.py`; запускайте через WSGI-сервер и reverse proxy.
