БЫСТРЫЙ СТАРТ:

1. РАСПАКОВАТЬ АРХИВ:
   tar -xzf eko-production-crm-complete-2026-08-31.tar.gz
   cd CRMLocal

2. НАСТРОИТЬ ОКРУЖЕНИЕ:
   cp .env.example .env
   # Отредактировать .env с production-значениями

3. УСТАНОВИТЬ ЗАВИСИМОСТИ:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

4. ИНИЦИАЛИЗИРОВАТЬ БД:
   python3 init_db.py
   # Или запустить миграции Alembic

5. ЗАПУСТИТЬ РАЗРАБОТКУ:
   python3 app.py
   # Откройте http://localhost:5000

6. ЗАПУСТИТЬ В PRODUCTION:
   docker-compose up -d
   # Откройте https://ваш-домен.ру
