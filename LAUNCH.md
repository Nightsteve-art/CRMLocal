# Запуск ветки `crm-v1-launchable`

Эта ветка создана как **безопасная стартовая версия**:

- текущая рабочая CRM и её маршруты сохранены;
- новый интерфейс добавлен отдельной страницей предварительного просмотра;
- новый дизайн доступен после входа по адресу `/ui-preview`;
- существующие страницы не были массово заменены непроверенными шаблонами.

## Локальный запуск

```bash
git checkout crm-v1-launchable
git pull origin crm-v1-launchable
python -m venv venv
source venv/bin/activate              # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`.

## Проверка нового UI

1. Войдите в CRM существующей учетной записью.
2. Откройте `http://127.0.0.1:5000/ui-preview`.
3. Страница использует реальные счётчики из базы: заказы, КП, остатки, задачи швейки.

## Важно

`ui-preview` — изолированная интеграция нового дизайна. Это сделано намеренно: новый дизайн должен переноситься в рабочие маршруты последовательно, с проверкой каждой страницы и без риска сломать текущую CRM.

## Файлы изменения

- `templates/modern_preview.html` — страница нового dashboard.
- `static/css/modern-preview.css` — стили нового интерфейса.
- `app.py` — защищённый маршрут `/ui-preview`.
