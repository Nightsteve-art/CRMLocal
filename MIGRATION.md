# Переход со старой CRM

1. Сделайте резервную копию старой SQLite БД и папки загрузок.
2. Запустите CRM NEW отдельно — она создаст `instance/crm_new.db`.
3. Проверьте справочники и рабочие процессы на тестовых данных.
4. Экспортируйте из старой CRM контрагентов, склад, КП, заказы и задачи.
5. Импортируйте данные поэтапно с сопоставлением внешних ключей.
6. Сверьте количества сущностей и остатки склада.
7. Только после приёмки переключайте пользователей.

## Сопоставление доменов

- `User` → `User`
- `Counterparty` → `Counterparty`
- `Proposal` → `Proposal`
- `Order` / `OrderItem` → `Order` / `OrderItem`
- `StockItem` / `StockTransaction` → одноимённые модели
- `MaterialRequest` → `MaterialRequest`
- `SewingTask` → `SewingTask`
- старые Kanban Project/Column/Card → новая упрощённая `KanbanCard.column`

Автоматический импорт не выполняется при старте, чтобы исключить повреждение производственных данных.
