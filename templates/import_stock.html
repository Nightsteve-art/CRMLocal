Инструкция по импорту

Поддерживаемые форматы

  • .xlsx - Excel файл (рекомендуется)
  • .xls - Старый формат Excel
  • .csv - Текстовый файл с разделителями

Обязательные колонки

Файл должен содержать как минимум эти колонки:

Название колонки
sku
Уникальный артикул товара
Название колонки
name
Название товара
Название колонки
quantity
Количество (число)

Дополнительные колонки

Эти колонки будут импортированы если они есть в файле:

unit
Единица измерения
category
Категория
description
Описание
min_stock
Мин. запас
location
Место хранения

Важная информация

  • Файл должен начинаться с заголовков (первая строка - названия колонок)
  • Если товар с таким SKU уже существует - он будет обновлен
  • Новые товары будут добавлены
  • Рекомендуем сделать экспорт текущих данных перед импортом
  • Максимальный размер файла: 16 МБ
